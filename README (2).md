# LLM Engineering Instructions

## Contents
- `AGENTS.md`: mandatory repository-wide engineering rules and Definition of Done.
- `.github/copilot-instructions.md`: GitHub Copilot entry point.
- `.agents/skills/*/SKILL.md`: specialized workflows for design, TypeScript, database, security, API, testing, review, and documentation.

Copy the contents of this directory into the root of your project. Keep `AGENTS.md` at the repository root. The specialized skill files are organized for agent skill discovery; verify the exact skill-discovery convention supported by your chosen coding agent before relying on automatic loading.
